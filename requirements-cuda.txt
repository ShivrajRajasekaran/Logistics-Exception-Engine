# GPU training requirements for Blackwell-class NVIDIA hardware (sm_120).
#
# WHY THIS FILE EXISTS
# The RTX 50-series (Blackwell, compute capability 12.0) has no compiled
# kernels in any torch wheel built against CUDA 12.1 or 12.4. Installing the
# default PyPI torch on this hardware produces a runtime failure of the form
#   "no kernel image is available for execution on the device"
# only once a tensor is actually moved to the GPU. Import and
# torch.cuda.is_available() can both succeed while training is still broken,
# so the install must be verified with a real allocation. See REPRODUCIBILITY.md.
#
# USAGE (Python 3.11 venv). Order matters: this file FIRST, then the base file.
#
#   pip install -r requirements-cuda.txt
#   pip install -r requirements.txt
#
# No extra pip flags are needed. requirements.txt pins `torch==2.7.0`, and under
# PEP 440 a specifier carrying no local version label matches any local version,
# so `==2.7.0` is satisfied by the `2.7.0+cu128` wheel installed above. pip
# reports "Requirement already satisfied: torch==2.7.0 ... (2.7.0+cu128)" and
# leaves the CUDA build in place. Verified with `pip install --dry-run`.
#
# Installing them in the OTHER order gives you the CPU wheel, and the CUDA file
# will then not downgrade it cleanly. If you are unsure which you have, check:
#
#   python -c "import torch; print(torch.__version__)"     # want 2.7.0+cu128
#
# Import success and torch.cuda.is_available() are NOT sufficient proof on this
# hardware. Confirm with a real allocation:
#
#   python -c "import torch; print(torch.zeros(8, device='cuda').sum())"


--extra-index-url https://download.pytorch.org/whl/cu128

torch==2.7.0+cu128
torchvision==0.22.0+cu128
